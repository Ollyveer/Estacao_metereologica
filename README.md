# Mini Estação Meteorológica IoT

> Experimento de construção de mini estação meteorológica IoT com sensores e um ESP32.

**Desenvolvido por Stefany Oliveira**

---

## Descrição

Este repositório contém o código-fonte, esquemas de montagem e documentação de um experimento de construção de uma mini estação meteorológica IoT. O sistema utiliza um microcontrolador ESP32 para coletar dados de temperatura, umidade e luminosidade ambiente, permitindo o monitoramento remoto das condições climáticas em tempo real.

---

## Hardware Utilizado

| Componente | Descrição |
|------------|-----------|
| **Microcontrolador** | ESP32 C3 Mini |
| **Sensor de Temperatura** | Sensor de temperatura ambiente |
| **Sensor de Umidade** | Sensor de umidade relativa do ar |
| **Sensor de Luminosidade** | LDR (Light Dependent Resistor) |

---

## Funcionalidades

- 📊 **Leitura de Temperatura** — Monitoramento contínuo da temperatura ambiente
- 💧 **Leitura de Umidade** — Acompanhamento da umidade relativa do ar
- 💡 **Leitura de Luminosidade** — Detecção da intensidade de luz ambiente via LDR
- 🌐 **Conectividade IoT** — Comunicação via Wi-Fi do ESP32 para envio de dados
- 📡 **Transmissão de Dados** — Envio das leituras para dashboard ou plataforma de monitoramento


---

## Como Usar

### Pré-requisitos

- Arduino IDE ou PlatformIO
- Bibliotecas para o ESP32 C3 Mini
- Drivers USB para comunicação serial
